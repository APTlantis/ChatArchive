# ChatArchive v0.1.2 Release Scope

Date: 2026-08-23

## Release Position

ChatArchive v0.1.2 is a Windows-first public release candidate for Microsoft Store distribution through MSIX.

The release target is:

- Windows desktop app.
- Microsoft Store distribution.
- MSIX package as the primary public Windows artifact.
- Partner Center package identity as the authoritative Store identity.
- Microsoft Store signing and update delivery after Store certification.
- Hash evidence for the final MSIX package produced from source.
- Local WACK evidence before Partner Center submission.
- MSIX install, launch, uninstall, and user-data preservation evidence before release-ready claims.

The release does not claim:

- GitHub Releases as the primary Windows distribution channel.
- NSIS or MSI as the public v0.1.2 release artifact.
- Trusted direct-download signing for external installers.
- Microsoft Store publication until Partner Center certification and publication are complete.
- Microsoft-signed package verification until the Store has re-signed the submitted package.
- macOS readiness.
- Linux readiness.
- Full cross-platform release certification.

The August 23, 2026 self-signed wrapper MSIX/WACK pass is retained only as evidence that the Store path is viable. It is not the release package shape because that experiment wrapped an installer. The v0.1.2 Store package must launch `chatarchive.exe` directly and must not package NSIS/MSI installers, private signing material, installer caches, or unrelated build output.

## Store Packaging Contract

The Store MSIX package is built by `scripts/release/build-store-msix.ps1` using `scripts/release/store-identity.json`, which is intentionally untracked. Copy `scripts/release/store-identity.template.json`, fill it with exact Partner Center values, and set `storeIdentityReserved` to `true` only after the name, package identity, publisher, and publisher display name are reserved.

The package manifest generated by the release script must use:

- `Application Executable="chatarchive.exe"`.
- A package architecture matching the built executable architecture.
- `runFullTrust`, with the Partner Center submission justification recorded in the identity config.
- Store-compatible four-part package versioning with a nonzero first segment and the fourth segment set to `0`; this package identity version may differ from the product release label `v0.1.2`.

Local self-signed packages are sideload smoke artifacts only. They do not prove Store publication, Store signing, Microsoft certification, or public release readiness.

## Cross-Platform Posture

ChatArchive is designed as a cross-platform Tauri app, but cross-platform support is not release-certified until it is tested on each target platform.

Windows is the first publish target. macOS and Linux releases remain pending virtual-machine validation and platform-specific packaging checks. Passing Windows build, UI, import, MSIX, and Store-prep checks does not certify macOS or Linux behavior.

## Feature Scope

This release should focus on the durable archive product:

- OpenAI export import.
- Filesystem-backed local archive library.
- SQLite-backed reader state.
- Conversation browsing and search.
- Code, document, asset, and link artifact indexing.
- Code, document, and asset explorer workflows.
- Knowledge organization with tags, collections, notes, and favorites.
- Markdown and document export paths.
- Local bundled rendering for Prism, Mermaid, and ZenUML.

## Deferred Scope

Project Intelligence is deferred out of this release.

The feature is valuable, but it is not part of the first public Windows release surface. It should not be advertised as a v0.1.2 capability, and user-facing controls for project scanning, project dashboards, candidate review, project timelines, aliases, and project membership curation should be removed or hidden before the release is claimed ready.

The deferred Project Intelligence work can return in a later version after its behavior, documentation, persistence model, test coverage, and cross-platform expectations are reconciled.

## Release Claim Wording

Use this posture for public-facing release notes before Store publication:

```text
ChatArchive v0.1.2 is a Windows-first local archive release prepared for Microsoft Store distribution through MSIX. macOS and Linux support remain pending platform verification. Project Intelligence is deferred from this release. Store publication and Microsoft-signed package verification remain pending until Partner Center certification and publication complete.
```
